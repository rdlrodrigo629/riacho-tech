# Contribuindo

Sugestões, correções visuais e melhorias de acessibilidade são bem-vindas.

1. Abra uma issue explicando o problema ou a proposta. Para alterações pequenas, envie diretamente um pull request.
2. Descreva o que mudou e como verificou no navegador, incluindo a largura de tela usada.
3. Mantenha a indicação visível de **dados simulados**. Não apresente números da demonstração como telemetria real.
4. Não envie credenciais, tokens, chaves de mapas, endereços internos, dados pessoais, posições reais ou capturas de sistemas de produção.
5. Separe qualquer proposta de integração com APKs ou servidores; ela precisa de documentação, autorização e testes de homologação.

Issues e pull requests são formas de colaboração com o projeto. Consulte o mantenedor antes de reutilizar ou distribuir o código fora deste repositório, pois ainda não há licença definida.
